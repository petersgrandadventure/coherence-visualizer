Reading the field

Every quantity the coherence monitor logs is expressed as particle behavior, so a glance tells you the state of the field — the same way the GCP Dot compresses network variance into a single color.

Color = statistical coherence

  • Scattered cool hues Baseline randomness. Health 0.65–0.85, entropy near 7.999 bits/byte.
  • Converging gold Coherence event. As Health climbs past 0.9 the hues collapse into a single band — spectral coherence rendered as color coherence.
  • Crimson turbulence Pazuzu critical (λmax/λMP > 1.30). The field destabilizes; the monitor would be calling for abort.

Shape = where the information is

  • Amorphous cloud (center) Local continuum coherence, CI_C. Its jitter amplitude is σ; its rotation speed is ρ.
  • Outer ring migration Conservation in action (Axiom H₁₃): when CI_B spikes, particles stream outward from the continuum cloud to the boundary ring in proportion to the transfer.
  • Seven-pointed star lock Gate 7: when the largest eigenvalue of the cross-gate correlation matrix crosses the Marchenko–Pastur edge (λmax/λMP > 1.15), particles trace the heptagram — the 7-fold residue of a genuine ledger packet.
  • Disintegration PSI below 0.3 — proximity to collapse. The structure loses its ability to hold form.

The seven gate tiles

G1 CPU entropy · G2 webcam photonics · G3 Schumann-band audio · G4 network timing · G5 clock drift · G6 non-local MI · G7 eigenvalue integrator. Tile height is each gate's normalized ledger-index activity; the brightness of that gate's particle family follows it.

Going live

Run the monitor, then serve its database with the bundled bridge: python3 coherence_bridge.py (from the folder containing coherence_ledger.db). Opening http://localhost:5005 loads this page already connected; or open the file directly and press Connect live. (The bridge defaults to port 5005 because macOS AirPlay occupies 5000.) The visualizer polls /api/latest every 2 s — one new packet per 4.2 s monitor cycle.

History playback

History loads the last 1200 logged packets (~84 minutes) from the bridge's /api/recent and replays them through the field. The timeline strip shows Health across the whole span — gold dots mark high-coherence events, red ticks mark Pazuzu flags — so you can scrub straight to the interesting moments. ⏵ plays at 1×, 8×, or 30× (1× = real time, one packet per 4.2 s). Without a bridge, it replays what this page has seen during the current session.
